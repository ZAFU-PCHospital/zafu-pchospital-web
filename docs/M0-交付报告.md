## Schema 变更

- 新增表：users、user_identities、password_credentials、roles、user_roles、
  member_profiles、join_applications、join_application_reviews、invite_codes、
  invite_code_redemptions、account_provisions、audit_logs。
- 新增索引 / 唯一约束：统一身份、成员档案、有效角色键、报名批次联系方式、邀请码摘要、
  Redemption 幂等键、Provision 来源与幂等键等。
- 软删除策略：User、UserIdentity、MemberProfile、JoinApplication、InviteCode 使用
  `deleted_at`；身份全局不复用。
- 兼容性说明：项目此前无数据库 Schema；这是 Phase 2 基线 Migration。

## API / Contract 变更

- 新增接口：`GET /api/v1/health`、`POST /api/v1/join-applications`；其余招募与邀请码
  v1 端点冻结文档和 Service 契约，留待后续页面/会话里程碑接线。
- 新增错误码：见 `src/lib/api/errors.ts`。
- 公共类型变更：见 `src/types/contracts.ts`。
- 影响模块：M1 账号、招募、邀请码和后续成员后台可直接依赖。
